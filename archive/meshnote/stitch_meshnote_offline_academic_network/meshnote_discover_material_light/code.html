Unit 3: Binary Search Trees & AVL Balancing

Academic Session 2024-25 · Prof. V. K. Kulkarni

A Binary Search Tree (BST) is a rooted binary tree data structure with the key of each internal node being greater than all the keys in the respective node’s left subtree and less than the keys in its right subtree.

Theorem 3.1 (AVL Balance Factor): For every node v, the heights of its subtrees differ by at most 1. Rebalancing is performed using Single (LL, RR) or Double (LR, RL) rotations.
