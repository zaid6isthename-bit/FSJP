# JVM VISION Parser & Supported Java Grammar

## 1. Overview

The **JVM VISION Parser** (`com.jvmvision.engine.parser.Parser`) is a deterministic recursive-descent parser designed specifically for an educational subset of Java. It converts a sequential stream of `Token` instances generated by `Lexer` into a strongly-typed Abstract Syntax Tree (`ASTNode`).

The parser is dual-mode:
1. **Full Class Structure**: Parses standard Java classes with fields, constructors, methods, and a `public static void main(String[] args)` entrypoint.
2. **Top-Level Educational Scripts**: If user input contains raw statements (e.g. `int x = 10; System.out.println(x);`) without a surrounding class or `main` boilerplate, the parser automatically wraps them into a synthetic `Main.main` class structure so students can experiment without boilerplate.

## 2. Supported Grammar (EBNF Specification)

Below is the formal EBNF (Extended Backus-Naur Form) specification implemented by the parser.

```ebnf
Program ::= ( ClassDeclaration | TopLevelStatement )* EOF

ClassDeclaration ::= [ "public" ] "class" IDENTIFIER [ "extends" IDENTIFIER ] "{" ClassMember* "}"

ClassMember ::= ConstructorDeclaration
              | MethodDeclaration
              | FieldDeclaration

FieldDeclaration ::= Type IDENTIFIER [ "=" Expression ] ";"

ConstructorDeclaration ::= IDENTIFIER "(" [ ParameterList ] ")" Block

MethodDeclaration ::= [ "public" | "private" ] [ "static" ] Type IDENTIFIER "(" [ ParameterList ] ")" Block

ParameterList ::= Parameter ( "," Parameter )*
Parameter ::= Type IDENTIFIER

Type ::= ( "int" | "double" | "boolean" | "String" | "void" | IDENTIFIER ) [ "[" "]" ]

Block ::= "{" Statement* "}"

Statement ::= Block
            | VariableDeclarationStatement
            | IfStatement
            | WhileStatement
            | ForStatement
            | ReturnStatement
            | TryCatchStatement
            | ThrowStatement
            | ExpressionStatement

VariableDeclarationStatement ::= Type IDENTIFIER [ "=" Expression ] ";"

IfStatement ::= "if" "(" Expression ")" Statement [ "else" Statement ]

WhileStatement ::= "while" "(" Expression ")" Statement

ForStatement ::= "for" "(" ( VariableDeclarationStatement | ExpressionStatement | ";" )
                           [ Expression ] ";"
                           [ Expression ] ")" Statement

ReturnStatement ::= "return" [ Expression ] ";"

TryCatchStatement ::= "try" Block "catch" "(" IDENTIFIER IDENTIFIER ")" Block

ThrowStatement ::= "throw" Expression ";"

ExpressionStatement ::= Expression ";"

Expression ::= AssignmentExpression

AssignmentExpression ::= LogicalOrExpression [ ( "=" | "+=" | "-=" | "*=" | "/=" ) AssignmentExpression ]

LogicalOrExpression ::= LogicalAndExpression ( "||" LogicalAndExpression )*

LogicalAndExpression ::= EqualityExpression ( "&&" EqualityExpression )*

EqualityExpression ::= RelationalExpression ( ( "==" | "!=" ) RelationalExpression )*

RelationalExpression ::= AdditiveExpression ( ( "<" | "<=" | ">" | ">=" ) AdditiveExpression )*

AdditiveExpression ::= MultiplicativeExpression ( ( "+" | "-" ) MultiplicativeExpression )*

MultiplicativeExpression ::= UnaryExpression ( ( "*" | "/" | "%" ) UnaryExpression )*

UnaryExpression ::= ( "!" | "-" | "++" | "--" ) UnaryExpression
                  | PostfixExpression

PostfixExpression ::= PrimaryExpression ( ( "++" | "--" ) )*

PrimaryExpression ::= Literal
                    | "this"
                    | IDENTIFIER [ "(" [ ArgumentList ] ")" ]
                    | "(" Expression ")"
                    | ObjectCreation
                    | ArrayCreation
                    | PrimaryExpression "." IDENTIFIER [ "(" [ ArgumentList ] ")" ]
                    | PrimaryExpression "[" Expression "]"

ObjectCreation ::= "new" IDENTIFIER "(" [ ArgumentList ] ")"

ArrayCreation ::= "new" Type "[" Expression "]"
                | "{" [ Expression ( "," Expression )* ] "}"

ArgumentList ::= Expression ( "," Expression )*

Literal ::= INTEGER_LITERAL
          | DOUBLE_LITERAL
          | STRING_LITERAL
          | "true"
          | "false"
          | "null"
```

## 3. Operator Precedence Hierarchy

The parser enforces standard Java operator precedence using stratified recursive functions:

| Precedence Level | Operators | Associativity | AST Node |
| :---: | :---: | :---: | :--- |
| **1 (Lowest)** | `=` `+=` `-=` `*=` `/=` | Right-to-Left | `AssignmentNode` |
| **2** | `\|\|` | Left-to-Right | `BinaryExpressionNode` |
| **3** | `&&` | Left-to-Right | `BinaryExpressionNode` |
| **4** | `==` `!=` | Left-to-Right | `BinaryExpressionNode` |
| **5** | `<` `<=` `>` `>=` | Left-to-Right | `BinaryExpressionNode` |
| **6** | `+` `-` | Left-to-Right | `BinaryExpressionNode` |
| **7** | `*` `/` `%` | Left-to-Right | `BinaryExpressionNode` |
| **8** | `!` `-` (unary) `++` `--` | Right-to-Left | `UnaryExpressionNode` |
| **9 (Highest)** | `.` (field/method) `[]` (array index) `()` (call) | Left-to-Right | `FieldAccessNode`, `ArrayAccessNode`, `MethodCallNode` |

---

## 4. Error Handling & Diagnostics

When encountering invalid or unsupported syntax:
- The parser captures the token's 1-indexed `line` and `column`.
- Generates a clear error message describing what was expected vs what was found.
- Throws `ParseException` which is converted into structured JSON diagnostics by Spring Boot:

```json
{
  "valid": false,
  "errors": [
    "Line 8, Column 15: Expected ';' after variable declaration, but found 'identifier'"
  ]
}
```

For constructs beyond the supported subset (such as lambda expressions `->`, streams, inner interfaces, or reflection), the parser cleanly rejects the construct with:
> *"This construct isn't supported by JVM VISION's educational simulator yet."*
